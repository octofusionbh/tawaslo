## The model, in one line

- **Orderlo** = hosts buy it themselves (Starter / Pro).
- **Tawaslo** = agencies pay (Freelancer / Professional / Enterprise / Partner); they get **coupons** — each = 3 months free Orderlo for a client venue.
- **One venue = one bill.** Orderlo also earns the **Tap** fee on every order.

Full detail in `blueprint.md`.
